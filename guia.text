Guia de lo aprendido e instalado

1- instalar las dependencias npm nodemon, dotenv, env-var, json-server.


2.- para usar el json server tenemos que ir al packege.json y en la parte de star usar "--watch" asi: 

"----------"start": "json-server --watch db.json"-------------"


3- Para usar el nodemon, en la parte de dev tenemos que poner nodemon y poner donde esta la app principañ:

"----------"dev": "nodemon src/app.js"-------------"
